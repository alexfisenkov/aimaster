# AI Мастерская

AIMaster ведёт идею от сценария и плана кадров до выбранных изображений и видео. Проект можно закончить переносимым комплектом материалов без MP4 или собрать ролик. Локальная страница открывает именно текущий проект; кнопки запускают задания через явно включённый контроллер Codex или Claude. Личные проекты, инструкции и библиотека лежат отдельно от установленного навыка.

Нужен Python 3.11+. Поддерживаются macOS, Linux и Windows без WSL. Подключения SYNTX, Higgsfield, Magnific и fal входят в настройку, но вход в аккаунт, доступность моделей и расход кредитов проверяются отдельно. Для монтажа доступна мастерская AIEditing.

## Установка

Передайте агенту, который умеет работать с файлами и терминалом:

```text
Установи AIMaster из https://github.com/alexfisenkov/aimaster. Сначала прочитай INSTALL_WITH_AGENT.md. Бесплатные необходимые программы ставь официальным менеджером ОС, если есть права; установи навык для моего агента и запусти family_setup.py setup --install-deps --json из фактической папки навыка. Покажи шаги, где мне нужно подтвердить права ОС или войти в аккаунт. Не выдумывай успешный вход, не запускай платную генерацию, не перезаписывай чужие MCP-настройки и не передавай секреты в чат. Перечитай установленные пути и статус; один раз спроси, включить ли автообновления.
```

Если есть Node/npx, команда установки самого навыка:

```sh
npx skills add https://github.com/alexfisenkov/aimaster/tree/main/skills/aimaster --skill aimaster -g -a codex -a claude-code
```

После неё агент находит реальный `<skill>` и запускает `python3 <skill>/scripts/family_setup.py setup --install-deps --json` (на Windows команда Python может быть `py -3`). Установка через Git clone и `skills/aimaster/scripts/install.py` тоже поддерживается; подробности в [инструкции агенту](INSTALL_WITH_AGENT.md). Частичный статус означает, что нужен системный доступ или вход, а не успешное подключение.

В Codex напишите `$aimaster Хочу ролик о …`, в Claude Code — `/aimaster`. Выберите работу с уточнениями или полностью автоматически. Для видео решите, нужен ли монтаж или достаточно комплекта материалов. В автоматическом режиме агент покажет короткий бриф и одно предупреждение о расходе кредитов, после одобрения не будет требовать обычных промежуточных ответов и не ограничит число материалов. В режиме с уточнениями кнопка платной генерации разрешает один показанный запуск. Загруженный вами файл остаётся исходным материалом; новая генерация нужна только по вашему запросу.

Автообновление включается один раз по вашему решению и применяется между заданиями. Пакеты AIMaster, SYNTX и AIEditing имеют локальные копии для отката; серверы сторонних сервисов откатить нельзя. Если старая версия не читает новые данные, рабочие данные сохраняются, а совместимый старый снимок можно открыть отдельно. [Архитектура](docs/architecture.md) и [выпуски](RELEASES.md).

# Start AIMaster

If the skill is not installed, follow the canonical [installation instructions](https://github.com/alexfisenkov/aimaster/blob/main/INSTALL_WITH_AGENT.md) or the [package README](../README.md). The installed `<skill>` folder contains `SKILL.md`, `scripts/`, `studio/`, `guides/`, and `references/`. Locate it from the host's installed skill list; never infer a repo root above it. `python3` below means the `python_cmd` the installer reports; on Windows that may be `py -3`.

Run `python3 <skill>/scripts/family_setup.py status --json` first. The full family setup is `family_setup.py setup --install-deps --json`; it handles AIMaster, SYNTX, Higgsfield, Magnific, fal and AIEditing. `--syntx-upload-destination hidden|uploaded` is an explicit choice when relevant; neither option broadens local file access. `--auto-update on` is the user's one-time opt-in, not a silent default. Free prerequisites can be installed automatically where the OS manager and permissions allow. The user completes OS admin prompts, host login and provider OAuth. The script reports partial setup rather than inventing success. See [update policy](update-check.md).

Choose a persistent workspace outside the installed package and run `creator_studio.py workspace init WS`; register it for update compatibility checks with `family_setup.py register-workspace --workspace WS --json`. Create a project immediately (`creator_studio.py project create WS ID --title TITLE --type photo|video|mixed --mode guided|autopilot`). Run `creator_studio.py serve WS --port 0` and open its returned exact `?project=ID` URL. Reuse a running server for that workspace. If the host cannot open a browser, show the URL and continue in chat. The controller is a separate explicit process: `creator_studio_operator.py run WS --agent codex|claude`; check `status WS` before implying that UI action buttons can run agent work.

Telegram is optional: `creator_studio_telegram.py setup-ui` accepts the token in a protected local UI; `run --workspace WS [--agent codex|claude]` connects the same workspace. Do not put credentials in chat or commands. If the Mini App cannot authenticate/load, use its visible retry and text transport. Native Telegram operation on Windows/Linux still needs live acceptance.

# GPT Image: генерация и редактирование

Проверено 2026-11-05 по [официальному руководству OpenAI API](https://developers.openai.com/api/docs/guides/image-generation). Руководство относится к OpenAI API; ChatGPT и агрегаторы могут иметь другие controls и доступность. На дату сверки документация перечисляет GPT Image 2.5 Sunburst/Flare и GPT Image 2. Не переносите API-параметры в сторонний UI по одному совпадению имени.

## План кадра

Сформулируйте назначение кадра, формат и главный визуальный объект. Для нового изображения задайте предмет, действие, ракурс, окружение, свет и допустимый стиль. Для точной правки назовите входное изображение, целевую область, требуемое изменение и всё, что должно сохраниться. Для нескольких референсов назначьте каждому роль и проверьте способ передачи файлов в выбранной операции.

## Текст и брендинг

Перепишите обязательные надписи отдельным списком с точным написанием. Логотипы, упаковку и фирменные цвета сверяйте с оригиналами; генеративный результат не является доказательством точного воспроизведения. Для публичного применения проверьте права на изображения и изображённых людей.

## Итерация

Оцените композицию, детали, текст, количество объектов, физическую правдоподобность и сохранение инвариантов. Следующую правку формулируйте как изменение одной группы ошибок. Сохраняйте исходный промпт, выбранную модель и результат, но не переносите приватные файлы или ключ API в публичный guide. Цены, размеры и параметры вызова берите из документации выбранного API на момент запуска.

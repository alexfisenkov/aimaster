# Личный стиль сценариев: подключение по желанию автора

Это новый публичный маршрут, составленный 2026-11-05. Исходный персональный корпус автора, примеры конкурентов и локальные пути не входят в поставку. Здесь нет готового «голоса Александра» по умолчанию. Пользователь может добавить свои опубликованные сценарии и правила в личный workspace, а затем явно выбрать эту инструкцию для конкретного проекта.

## Создайте профиль

Соберите 3–5 своих текстов с правом повторного использования. Для каждого укажите цель ролика, аудиторию, сильный хук, конфликт, доказательство, поворот и один призыв к действию. Отделите общую форму от личных фактов: факты о себе и результаты клиентов должны приходить только от владельца и подтверждаться исходником. Примеры других авторов годятся для анализа механики, но не для дословного переноса.

## Сценарная формула

Начните с конкретной проблемы зрителя. В первых строках покажите напряжение или неожиданный результат без неподтверждённого обещания. Затем дайте механизм, один наблюдаемый пример и короткий вывод. Финальный CTA предлагает ровно одно действие и не обещает несуществующий материал. Размечайте шоты и экранные надписи так, чтобы монтажёр мог проверить, где появится каждый тезис.

## Проверка

Сравните черновик с собственными примерами по ритму и словарю, затем отдельно проверьте факты и права. Уберите чужие узнаваемые фразы и неподтверждённые цифры. Прочитайте сценарий вслух, проверьте длительность, ясность и один CTA. При смене личной библиотеки сохраните её ревизию в проекте, не переписывая встроенный bundle.

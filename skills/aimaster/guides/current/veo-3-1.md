# Veo 3.1: видеопромпт с отдельной проверкой поверхности

Проверено 2026-11-05 по [официальной документации Gemini API для Veo](https://ai.google.dev/gemini-api/docs/veo). Она описывает семейство Veo 3.1 и параметры API; Google Flow и Gemini UI могут предлагать иные операции. Старое авторское руководство VEO не содержит подтверждённой точной версии, поэтому его числа и кнопки нельзя читать как настройки Veo 3.1.

## Подготовка сцены

Опишите субъект, локацию и изменение во времени. Укажите крупность, направление движения камеры, главное действие и звуковую задачу. В сложной истории делайте отдельные промпты для шотов с явными началом и концом. Для image-to-video прикрепите разрешённый исходник способом, который действительно поддерживает выбранная операция, и опишите движение, а не пытайтесь заново нарисовать кадр.

## Настройки и референсы

Перед запуском зафиксируйте точную модель, маршрут API/Flow/UI и доступные controls. Число входов, длина, формат, аудио и ограничения берутся из актуальной схемы этого маршрута. Не переносите названия полей API в интерфейс Flow. Для нескольких референсов запишите их роли и проверьте связь между файлами и промптом.

## Приёмка

Воспроизведите весь файл со звуком. Проверьте причинность действия, целостность персонажа, синхронизацию, артефакты и монтажные границы. Сохраните выбранный клип и фактические настройки. Если результат не проходит QA, меняйте один шот или один референс и генерируйте новую версию в пределах разрешения проекта.

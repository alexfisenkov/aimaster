## Как настроить проект:

1. Создай проект в ChatGPT (⚙️ → Projects)
2. В поле **Instructions** вставь текст выше (между ```)
3. Загрузи оба файла:
   - `инструкция для ChatGPT по описанию для YouTube.md`
   - `ютуб описание.md`
4. Готово — один проект, два режима, автоматический роутинг

## Примеры запросов:

**→ Режим 1 (названия и описания):**
- "Сделай название для видео про промпты ChatGPT"
- "Нужно 6 вариантов заголовка, тема — обзор Midjourney"
- "Запакуй видео: я рассказываю про 5 AI-инструментов"
- "Видео про ошибки в промптах — придумай title"

**→ Режим 2 (тайм-коды и главы):**
- "Вот транскрипция эфира 3 часа, сделай описание с тайм-кодами"
- "Разбей запись на главы" + [файл с временны́ми метками]
- "Обработай стрим" + [текст с (00:01) (01:23) ...]
- "Сделай YouTube description с chapters для этого эфира"

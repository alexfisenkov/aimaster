## Как использовать:

1. Создай новый проект в ChatGPT
2. Зайди в настройки проекта (⚙️)
3. В поле **Instructions** вставь текст выше (между ```)
4. Загрузи файл `grok-aurora-chatgpt-instruction.md` в проект
5. Готово! Теперь пиши любой запрос — ChatGPT будет создавать идеальные промпты для Grok

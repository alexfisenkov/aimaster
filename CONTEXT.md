# Контекст AIMaster

| Термин | Значение |
|---|---|
| AIMaster | Инструмент для превращения идеи в материалы и, по выбору, готовый ролик. |
| Семейство скиллов | AIMaster вместе с AISpa и AIEditing, использующие общий язык интерфейса и установки. |
| Проект | Сохранённая работа с брифом, материалами, решениями, версиями и этапами. |
| Рабочая область | Постоянное место пользовательских проектов, материалов, инструкций и библиотеки. |
| Бриф | Согласованное описание задачи, сервиса, референсов, инструкций и необходимости монтажа. |
| Пошаговый режим | Работа с существенными вопросами и видимым выбором следующего шага. |
| Полный автомат | Работа по утверждённому брифу без новых обязательных вопросов до базового результата. |
| Руководство | Инструкция, выбранная для конкретной задачи, модели и способа генерации. |
| Встроенное руководство | Руководство из поставляемого набора AIMaster. |
| Пользовательское руководство | Добавленная пользователем инструкция, хранящаяся отдельно от установки. |
| Библиотека | Постоянные карточки персонажей, товаров, мест, стилей и связанных материалов. |
| Референс | Материал, сохранённый как опора для проекта или генерации. |
| Материалы | Выбранные результаты проекта, выдаваемые законченным комплектом без монтажа. |
| Монтаж | Сборка ролика из выбранных материалов с редактируемой и переносимой выдачей. |
| Проход улучшений | Необязательная работа после базового результата, создающая новую версию. |

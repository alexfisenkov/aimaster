# ADR 0010. Ограниченный авторинг из host-задачи

## Контекст

Host-задаче нужен доступ к каноническому пакету и обычным операциям авторинга, при этом её полномочия должны оставаться ограниченными конкретным проектом и действием. Результат host необходимо сверять с каноническим состоянием; разрешение на авторинг не должно включать произвольное выполнение команд или завершение платной генерации.

## Решение

Host может не передавать контрольную сумму состояния: родительский исполнитель самостоятельно вычисляет и сверяет канонический digest вместе с идентичностью, ревизией, результатами и историей. Переданная host контрольная сумма также сверяется. Host получает доступ на чтение только к зафиксированной версии пакета; идентификатор версии проверяется, чтобы исключить незаметное расхождение пакета. Обычный авторинг выполняется через один ограниченный задачей шлюз командной строки с фиксированными исполняемым файлом, пакетом, рабочей областью, действием и путём запроса. Шлюз принимает типизированные операции, проверяет выполняемое действие, проект, ревизию и разрешённые файлы, затем передаёт запись существующим средствам авторинга с их историей. Платные результаты завершает родительский сборщик по квитанции, вне этого шлюза.

## Почему

Типизированный вход использует действующие правила ревизий и истории, сохраняя минимальные полномочия. Общий доступ к командной оболочке или всему файловому дереву расширил бы доступ сверх необходимого. Родительская сверка не зависит от способности host сформировать хэш. Разделение платного результата и обычного авторинга не позволяет обойти подтверждение сбора.

## Последствия

Неизвестные операции, чужой проект или действие, устаревшая ревизия, обход разрешённой области и символические ссылки отклоняются. Диагностика ограничивается классом ошибки и кодом завершения, без вывода host, подписанных ссылок и секретов. Доступ шлюза ограничен обычным авторингом и не подразумевает поддержку каждой операции или каждого host. Версия пакета, читаемая host, должна быть точной и неизменяемой на время задачи.

# Handoff: редизайн дашборда v2 (десктоп + мобильная версия)

Репозиторий: `alexfisenkov/aimaster`, ветка `main`, область `skills/aimaster/studio/static/`.

## Обзор
Визуальный редизайн текущего дашборда v2 AI Мастерской. Структура продукта, тексты, пути и правила не меняются: те же пять шагов (Сценарий → Кадры → Видео → Звук → Сборка), полка референсов, строки сцен, тёмный просмотрщик, окно «запрос агенту». Меняется подача: аккуратнее карточки, статусы, степпер, липкие шапка и футер, плюс полноценная мобильная раскладка.

## О файлах
`dashboard-v2-redesign.dc.html` — **дизайн-референс в HTML**, интерактивный прототип внешнего вида и поведения. Это не продакшн-код, копировать его не нужно. Задача — воссоздать дизайн в существующем коде `studio/static` (vanilla JS-модули `ui/v2/*.js` + CSS `styles/v2/*.css` + токены `styles/tokens.css`), сохранив текущую модель данных, API и контракт `buildChatPrompt()`.

Открыть прототип: положить оба файла рядом и открыть `.dc.html` в браузере (`support.js` — рантайм прототипа, в продукт не переносится). В правом нижнем углу хоста есть настройки демо: `device` (Авто/Десктоп/Телефон), `startStage`, `railOpen`. В прототипе все данные демонстрационные, а кнопка «Имитировать ответ агента» — заглушка, в продукт она не идёт.

## Fidelity
**High-fidelity.** Цвета, радиусы, размеры и отступы финальные. Шрифт — системный стек из `tokens.css` (`--font-ui`).

## Мобильная версия (< 760px)
- **Шапка** sticky: ☰ 44px (выдвижная панель проектов шириной `min(86%, 320px)`, затемнение `rgba(14,16,19,.5)`), название 17px и строка статуса цветом пилюли, 💬 44px.
- **Путь** — 5 равных кнопок в ряд: кружок 24px и подпись 11px, без линий.
- **Контент** с padding 18/14. H1 24px.
  - Режим «Как делаем ролик» — segmented на всю ширину, 40px.
  - Референсы: группы вертикально, плитки 112px с горизонтальным скроллом и `scroll-snap`.
  - Сцена — карточка: слоты кадров сеткой `minmax(130px, 1fr)` 16:10; «В кадре» — горизонтальный ряд квадратов 40px; снизу чип промпта и «＋», который открывает шторку «референс только для сцены / видеореференс / свой кадр».
  - Видео — крупные превью 16:9. Звук — список строк с мини-волной 86×52 и «›».
- **Футер** sticky: плашка «Осталось решить: N · показать ›» (40px) открывает шторку со списком, каждый пункт ведёт в просмотрщик. Главная кнопка на всю ширину, 50px, радиус 14. Учтён `env(safe-area-inset-bottom)`.
- **Шторки (bottom sheet)**: радиус `20 20 0 0`, хэндл 40×4, пункты по 50px.
- **Просмотрщик** на весь экран без радиуса. Вкладки занимают отдельный ряд на всю ширину, стрелок нет — варианты листаются **свайпом** (порог 50px). Правая колонка уходит под основную.
- **Окно агента** выезжает шторкой снизу.
- Все цели нажатия ≥ 44px.

## Поведение и состояние
- `stage` (0–5) — текущий шаг; `view` — открытый пройденный экран; будущие шаги закрыты.
- Статус позиции:
  - нет вариантов → «не задан» (серый `#b4b9bf`);
  - есть варианты, ничего не выбрано → «выберите из N» (`#d08a1c`);
  - выбран → «выбран K из N» (`#15864a`);
  - свой файл → «ваш файл».
- «Осталось решить» считается по текущему шагу: все референсы и нужные слоты кадров, клипы, сборка. Пустые слои звука не блокируют.
- Главная кнопка активна только при 0 оставшихся; одобрение переводит на следующий шаг и пишет запись в историю.
- Все изменяющие действия, кроме «Оставить», «Отклонить», «Скрыть» и «Убрать из работы», идут через окно запроса агенту.
- Тосты: снизу по центру, `#111315`, 2.6 с.

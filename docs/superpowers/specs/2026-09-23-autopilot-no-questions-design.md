# Автопилот без вопросов, библиотека рабочей папки, проверка MCP скриптом

Дата: 2026-09-23. Ветка: `feat/autopilot-no-questions`. Решения владельца
получены в диалоге 2026-09-23.

## Проблема

1. `project.mode = autopilot` движок нигде не читает; это слово в инструкциях.
   Инструкции в шести местах требуют спрашивать «даже в автопилоте»
   (`SKILL.md:67-69, 95, 169-177`, `references/creator-studio.md:22-23`,
   `references/onboarding.md:49-50`, `references/writing-guides.md:3-4`,
   `references/model-selection.md:50`, `references/completion-loop.md:78-79`,
   `references/adapter-contract.md:9`).
2. Платные действия (`vary`, `regenerate`, `generate` — `studio/ledger.py:74`)
   требуют разрешения (grant) независимо от режима.
3. Библиотеки персонажей/голосов между проектами нет: референсы живут внутри
   проектов и в общем `media/`.
4. Проверка подключённых MCP — только словами (`references/provider-preferences.md`),
   модель регулярно заявляет «MCP не подключён», когда он подключён.
5. Рабочая папка создаётся руками по инструкции; `instructions/` появляется лениво.

## Решения владельца

- В автопилоте после одобрения идеи — **ни одного вопроса** до готового ролика.
- **Списания без подтверждения и без лимита.**
- Персонажи, голоса, референсы и инструкции, уже загруженные в рабочую папку,
  подхватываются сами.
- Нейросеть, названная в идее, используется; не названа — агент выбирает сам
  по задаче, числу референсов, поддержке видеореференсов.
- Никогда не заявлять «нет MCP», не проверив по-настоящему; проверка работает
  у любого пользователя на любом компьютере.
- Всё живёт в рабочей папке скилла и появляется при установке/активации.
- Режим «с уточнениями» (`guided`) не меняется.

## Устройство

### 1. Канон автопилота — `references/autopilot.md`
Единственное место, где описано поведение режима. Все перечисленные выше
места заменяют «even in autopilot» на «в `guided` — так; в `autopilot` —
см. `references/autopilot.md`». Порядок автопилота после одобрения идеи:
проверка инструментов (§4) → подбор из библиотеки (§3) → гайд промптов (берёт
точное совпадение из реестра, иначе пишет без гайда и отмечает это) →
способ генерации (решает сам) → модель (из идеи, иначе выбор по
`model-selection.md` «выбрать за меня») → референсы (библиотека, иначе
генерирует) → промпты → генерации → выбор вариантов → одобрение этапов →
сборка. Остановка допустима только при физической невозможности (нет ни
одного маршрута на нужную модальность, провайдер вернул ошибку оплаты) —
тогда отчёт, а не вопрос.

### 2. Списания — кодом
Если `project.mode == "autopilot"`, постановка платного действия в очередь
выдаёт разрешение сама (без отдельной команды `grant`), с пометкой
`issued_by: autopilot`, и пишет в историю проекта запись вида
`autopilot-grant` (действие, цель). В `guided` поведение прежнее.
При включении автопилота (`mode set --mode autopilot`, `project create
--mode autopilot`) CLI печатает в выводе поле
`notice: "Автопилот тратит кредиты без подтверждения"`; агент показывает эту
строку пользователю один раз.

### 3. Библиотека рабочей папки — `library/`
```
<workspace>/library/
  index.json            реестр записей
  characters/ voices/ locations/ products/ styles/ other/   файлы
```
Запись: `{library_id, kind, label, aliases[], files[{path, sha256, media}], voice_of?, source: {project_id, reference_id}?, added_at}`.
CLI (`creator_studio.py`):
- `library list <ws> [--kind K]` → JSON;
- `library add <ws> --kind K --label L [--alias A]… --file PATH` — копирует файл
  в `library/<kind>/`, дубли по sha256 не заводит;
- `library import <ws> --from-projects` — собирает референсы с файлами из всех
  проектов, без дублей; локальность сцены — привязка внутри проекта, поэтому
  локальные референсы-картинки берутся, а локальные видеореференсы (клипы
  конкретного ролика) пропускаются с причиной `project_clip`; сгенерированный
  референс даёт выбранный результат, иначе принятый, иначе `no_selected_result`;
- `library match <ws> --text "идея"` — записи, чьё имя или псевдоним встречается
  в тексте (без учёта регистра и окончаний по простому правилу основы);
- `reference add … --from-library <library_id>` — регистрирует файл библиотеки
  как ассет проекта и создаёт референс `source=upload`.
Индекс пишется атомарно, под блокировкой; пути — только внутри `library/`.

### 4. Проверка инструментов — `scripts/detect_tools.py`
Читает конфигурации подключений без сети: Claude Code (`~/.claude.json`
глобально и для текущей папки, `.mcp.json` в папке и родителях, `.mcp.json`
установленных плагинов), Codex (`~/.codex/config.toml`), Gemini
(`~/.gemini/settings.json`), Cursor (`~/.cursor/mcp.json`), плюс
`<config-home>/aimaster/preferences.json`. Выводит JSON: по средам — имена
серверов и тип (stdio/http); сводку по известным провайдерам генерации
(higgsfield, magnific/freepik, syntx, fal, replicate, elevenlabs, kling,
runway, luma, openai, google). **Никогда не выводит значения переменных,
заголовков, токенов, аргументов с ключами** — только имена. Код 0 всегда,
если удалось прочитать хоть что-то.
Правило в инструкциях: прежде чем сказать «нет инструмента/MCP», агент
обязан (1) найти его в собственном списке инструментов (в Claude Code —
`ToolSearch` по имени сервера), (2) запустить `detect_tools.py`, (3) сделать
бесплатный пробный вызов (баланс, список моделей). Сервер в конфиге, но не
виден в сессии → сказать это точно и предложить переподключение; в автопилоте —
взять следующий доступный маршрут той же модальности.

### 5. Рабочая папка — `workspace init`
`creator_studio.py workspace init <ws>` (идемпотентно): `projects/`, `media/`,
`instructions/`, `library/` с подпапками и пустым `index.json`, `.studio/`,
`README.md` с объяснением раскладки. `getting-started.md` и `SKILL.md`
вызывают её при первой активации в папке вместо ручных `mkdir`.

## Проверка
- Python-тесты: автовыдача разрешения только в автопилоте; история; guided
  без изменений; библиотека (добавление, дубли, импорт, match, from-library,
  пути вне `library/` отвергаются); `workspace init` идемпотентен;
  `detect_tools.py` на синтетических конфигах с секретами — ни одного
  секрета в выводе.
- Прогон на копии рабочей папки владельца: `library import` находит
  Александра и Артёма; `library match` по фразе с их именами; автопилотный
  проект: платное действие ставится в очередь без `grant`.
- Инструкции: поиск по `references/` и `SKILL.md` не находит «even in
  autopilot», «wait for the user» в контексте автопилота.

## Вне этой ветки
Строка «автопилот тратит без вопросов» в дашборде — после слияния редизайна v3.

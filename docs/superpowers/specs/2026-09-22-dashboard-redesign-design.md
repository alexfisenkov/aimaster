# Дашборд AI Мастерской: перестройка под минимализм

Дата: 2026-09-22. Ветка: `feat/dashboard-redesign`. В `main` не сливается,
пока владелец не проверит дашборд целиком на существующем проекте.

## 1. Зачем

Владелец после живой работы: «много лишнего», «кнопки этапов — кнопки, а не
этапы», «нет возможности видеть все варианты и выбирать», «одна сущность на
двух экранах», «должно быть легко, красиво, структурно». Правило, принятое в
диалоге: **на экране не больше двух кнопок; выбирать — листалкой; всё редкое —
за «···»; ничего лишнего.**

Не входит в эту ветку (отдельные проекты, по порядку после неё): промпт
«скачай и разложи файлы», расширенный саунд-дизайн (переозвучка, перевод,
липсинк), монтаж (Remotion, Whisper, подрезка в дашборде).

## 2. Решения владельца (зафиксированы)

1. Экраны: **Сценарий → Кадры → Видео → Звук → Сборка**. «Кадры» — один
   экран: референсы + сцены + промпты + картинки; отдельного «Изображения» нет.
2. Кнопки: **выбор кликом, генерации через чат.** Принять вариант, отклонить,
   скрыть, вернуть — мгновенно в дашборде (существующий `POST /api/actions`).
   Всё, что стоит денег или требует агента (ещё вариант, изменить промпт,
   загрузить файл, написать промпты, собрать ролик) — промпт в чат, в котором
   уже указаны сцена, версия промпта и выбранный вариант.
3. Раскладка «Кадры»: **вариант A** — полка референсов сверху, сцены списком.
4. Просмотрщик: **вариант C** — тёмный, на весь экран, большая картинка,
   листалка ‹ ›, плёнка вариантов, две кнопки: «Оставить этот» и «＋ Ещё
   вариант»; остальное за «···». Справа — промпт с листалкой версий и зоны
   референсов.
5. Модель сцены (дословно по владельцу): сцена = описание + промпт. В сцене
   независимо и необязательно: какие **общие референсы** участвуют; **свой
   референс только этой сцены**; **видеореференс** (движение / продолжение /
   правка — для Seedance 2.x, Kling 3.0 и подобных); **кадры** — первый и/или
   последний, свой файл или сгенерированный. Кадров может не быть.
   «Способа генерации» у сцены нет.
6. Общие референсы — по группам с подписями: **Персонажи** (с голосом),
   **Локации**, **Реквизит**, **Стиль**, плюс **Прочее** — «загрузить что
   угодно» без категории.
7. Как делаем ролик — один переключатель на весь проект: «кадр за кадром» /
   «одним заходом» (существующий `gen_mode`).
8. Промпты — видимые поля с листалкой версий (v2 из 3), под версией — какие
   варианты по ней сделаны; правка — через чат.

## 3. Экраны

Шапка везде одна: название проекта · тип · длительность · режим; справа одна
кнопка «💬 Агент» (открывает диалог с общим промптом «продолжить проект в
чате»). Ниже — **путь** из пяти шагов: полоса с состоянием «✓ одобрен / вы
здесь / дальше», под шагом одна строка подсказки. Шаги — не кнопки: клик
открывает пройденный шаг для просмотра, будущие недоступны.

Внизу каждого экрана — **одна главная кнопка** «Одобрить … → следующий шаг»
и строка «Осталось решить: …» (из `stage_readiness.reason` и собственного
подсчёта нерешённых). Кнопка неактивна, пока есть нерешённое.

### 3.1 Сценарий
Текст сценария (активная версия, листалка версий), раскадровка списком
(номер, название, время, текст). Кнопки: «Изменить сценарий → чат» за «···»,
главная — «Одобрить сценарий → Кадры».

### 3.2 Кадры (объединяет server-stages `image_plan` + `image_results`)
- Переключатель «Кадр за кадром / Одним заходом». При «одним заходе» над
  сценами — поле общего промпта с версиями.
- **Общие референсы** в четыре подписанные группы + «Прочее»; плитка =
  картинка выбранного варианта, имя, статус («ваш файл» / «выбран 2 из 3» /
  «выберите» / «не задан»), число вариантов; «＋» → чат.
- **Сцены** списком. Слева: номер, название, время, описание (одна-две
  строки), строка «промпт v2 · готов» (клик — просмотрщик на промпте). Справа
  четыре строки: **В кадре** (аватары общих референсов, невключённые —
  приглушены), **Только здесь** (локальные референсы + «＋»), **Видеореференс**
  (плитка с подписью вида + «＋»), **Кадры** (слоты «первый» / «последний»:
  свой файл / N вариантов / пусто; статус «выбран» / «выберите из N»).
- Главная кнопка: при `image_plan` — «Одобрить промпты и референсы → кадры»
  (approve stage `image_plan`); при `image_results` — «Одобрить кадры → Видео»
  (approve `image_results`). Экран один и тот же.

### 3.3 Видео (`motion`)
Те же сцены списком; справа: слот клипа (N вариантов, статус), промпт движения
«v3 · готов», продолжение («с конца сцены 1»). Просмотрщик открывается на
вкладке «Видео». Главная — «Одобрить видео → Звук».

### 3.4 Звук (`audio`)
Четыре плитки слоёв (голос, музыка, эффекты, атмосфера) с числом вариантов и
статусом; просмотрщик с аудио-листалкой. Главная — «Одобрить звук → Сборка».

### 3.5 Сборка (`assembly`)
Плитка финального ролика (варианты), «Собрать → чат», «История решений».
Главная — «Принять ролик».

## 4. Просмотрщик (общий компонент)

Открывается кликом по сцене, референсу, слою, финальному ролику. Тёмный, на
весь экран, `Esc`/✕ закрывает, ← → листают, на телефоне свайп.

- **Шапка:** название · время · вкладки «Кадры | Видео | История» (для
  референса — без «Видео»).
- **Слева:** переключатель слотов («Первый кадр · 4 варианта / Последний кадр
  · нет»); холст с ‹ ›; подпись «Вариант 3 из 4 · выбран · по промпту v2»;
  плёнка вариантов с пометками (выбран / новый / отклонён / скрыт — отклонённые
  и скрытые приглушены, но листаются); последняя плитка «＋».
- **Кнопки:** «Оставить этот кадр» (direct `approve` на результат) и
  «＋ Ещё вариант» (чат). «···»: отклонить с комментарием (direct `reject`),
  скрыть/показать (`hide`/`unhide`), убрать из работы/вернуть
  (`retire`/`restore`), загрузить свой файл (чат), изменить промпт (чат).
- **Справа:** промпт с листалкой версий и мета «v2 · когда · по нему варианты
  3, 4», «Изменить → чат»; зоны «В кадре» (клик по аватару — включить/выключить
  референс в сцене: сейчас это команда чата `scene reference` — оставить через
  чат с промптом на одну галочку), «Только здесь», «Видеореференс».

## 5. Данные (только существующий snapshot)

`active_project`: `scenes[]` (`scene_id`, `title`, `script_block`,
`start_ms`, `end_ms`, `need_first`, `need_last`, `links`, `video_mode`,
`linkage_status`), `references[]` (`reference_id`, `tag`, `kind`, `label`,
`local`, `voice`, `source`, `has_asset`, `asset_url`), `positions[]`,
`image_prompts[]`/`motion_prompts[]` (`prompt_id`, `version_id`,
`parent_version_id`, `text`, `status`, `stale`, `decisions`),
`image_results[]`/`video_results[]` (`result_id`, `version_id`,
`parent_version_id`, `status`, `decision`, `asset_url`, `caption`),
`gen_mode`, `oneshot`, `stage`, `stage_readiness`, `stage_decisions`,
`history`.

- Варианты = все записи группы `result_id`, упорядоченные по цепочке
  `parent_version_id` (первый вариант — без родителя). «Выбран» = версия,
  на которую указывает `scene.links` / `oneshot.links` / позиция.
- Версии промпта = все записи группы `prompt_id` по той же цепочке. «По нему
  варианты N, M» — результаты, чей `parent_version_id`/`prompt_version_id`
  указывает на версию (если связи нет в snapshot — показывать только версии).
- Группы референсов: `kind` → Персонажи `character`, Локации `location`,
  Реквизит `product`, Стиль `style`, Видеореференсы `video` (внутри сцен),
  **Прочее `other` — новый допустимый `kind`** (правка `domain.py`,
  проекции, CLI `reference add --kind other`, тест).

Серверные стадии не меняются. Экран «Кадры» показывает `image_plan` и
`image_results` как один шаг.

## 6. Действия

- Direct (уже есть в `ui/actions.js`, `card-model.js`, `stage-approval.js`;
  сейчас отключены `readOnly: true` в `shell.js`): `approve`, `reject`,
  `hide`, `unhide`, `retire`, `restore` на результат; approve/reject стадии.
  Включить только эти. `vary`/`regenerate` в дашборде не показывать.
- Чат (`requestAgentPrompt`): каждый промпт начинается с «Открой проект «…»,
  сцена N «…»» и содержит версию промпта и выбранный вариант (`result_id`,
  `version_id`), чтобы агент действовал точно.

## 7. Код

Новые модули (≤ ~120 строк каждый), старые не удаляются до приёмки
(правило «вытесненное удаляем после приёмки»); переключение через новый
`index.html`-вход `app.js` → `ui/v2/`:

```
static/ui/v2/
  path-nav.js        путь из 5 шагов (модель + рендер)
  screen-map.js      stage ↔ экран, подписи, главная кнопка, «осталось решить»
  screen-scenario.js screen-frames.js screen-video.js screen-audio.js screen-assembly.js
  reference-shelf.js группы референсов
  scene-row.js       строка сцены с четырьмя зонами
  variants.js        модель вариантов/версий (чистые функции, тесты в node)
  viewer.js          просмотрщик: холст, листалка, плёнка, кнопки, «···»
  viewer-prompt.js   промпт с версиями и зонами
  chat-prompts.js    тексты промптов для чата (с контекстом варианта)
  decide.js          direct-действия через actions.js
static/styles/v2/    tokens-v2.css board.css viewer.css
```

Тесты: `node --test` на чистые функции (`variants.js`, `screen-map.js`,
`chat-prompts.js`, модель `scene-row`), `check_static_modules.mjs`, Python
тесты на `kind=other`. Браузерная проверка — на копии workspace владельца.

## 8. Порядок работ

1. Ветка, спецификация, `kind=other` (сервер).
2. Ядро: `variants.js`, `screen-map.js`, `path-nav.js`, оболочка v2.
3. Экран «Кадры»: полка, строки сцен.
4. Просмотрщик + промпт с версиями + direct-действия + чат-промпты.
5. Экраны Сценарий / Видео / Звук / Сборка.
6. Стили, телефон и Mini App, проверка в браузере на копии workspace.
7. Показ владельцу на его проектах; правки по отзыву; слияние.
